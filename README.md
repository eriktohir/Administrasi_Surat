# Administrasi_Surat
Rancangan App Administrasi Surat ini dibangun dengan framework Ionic + Vue (frontend) dan Python + MySQL (backend). Tujuan aplikasi ini untuk mempermudah dalam sirkulasi surat keluar masuk terdokumentasi dengan rapi dan memudahkan pencarian dokumen surat menyurat yang dibutuhkan, untuk sementara App ini masih dalam tahap Build dan pengembangan,
